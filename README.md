# DenuAnime 🎌

DenuAnime is a modern Android anime collection application built using **Jetpack Compose** and powered by the **Jikan API** (https://jikan.moe/).

The app allows users to browse, search, and explore anime titles, characters, and related information with a clean and responsive UI.

## 🛠 Tech Stack

- **Kotlin**
- **Jetpack Compose**

### 🏗 Architecture & Libraries
- MVVM Architecture
- Hilt (Dependency Injection)
- Retrofit (Networking)
- Coil (Image Loading)
- Jetpack Compose Type-Safe Navigation
- Kotlin Coroutines & StateFlow

### 🌐 API
- Jikan API (https://jikan.moe/)

---

## ✨ Features

- Browse trending and popular anime
- Search anime and characters
- Filter search results
- View detailed anime information
- Explore character profiles
- Modern Compose-based UI
